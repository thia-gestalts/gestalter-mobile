# Gestalter mobile

Capture a thought immediately, optionally attach an image, and revisit a small random selection of notes. Design the screens for one-handed use. The initial product is a native Android app. Keep record handling, sync behavior and acceptance examples portable so a future iOS implementation can follow the same contract.

The complete learner base lives on a fully synced device. The mobile UI exposes a deliberately small part of it: Capture (quick add, text and images only), a searchable Notes list, a full note editor (title, text, extra, aliases, tags, images, related records) and the Queue. Mobile has no dependency on desktop routes or UI.
