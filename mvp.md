# First usable Android release

Launch into a simple add-note screen. Save a text note with an optional image while offline. Provide a compact note CRUD editor for notes reached through capture or Queue. The Queue resurfaces a few random notes and honors the existing no-queue opt-out. A separate existing-notes library, search screen and OS share sheet are outside this release.

Olymp sign-in enables automatic E2E sync of the full base. Reopen after the process is killed, keep pending saves, then reconnect and see the note and image in desktop. A fully synced phone retains specialist records and attachments even when mobile has no screen for them.

Acceptance on Android: capture text and an image offline, restart, reconnect, edit a note from Queue and delete a disposable note. Verify the same changes on a second client.
